# JSHELL

What's up, this is the super epic JSHELL.

![JSHELL demo](./demo.gif)

You ever wish you could have a super watered-down shell, AND Joe Bartolozzi in it? Look no further than JSHELL, the first of its kind to EVER include Joe Bart!

## Installation

To install this, it's simple:

1. Clone the repository, **or** download the latest release
2. Install the requirements

```bash
pip install -r requirements.txt
```

## Usage

After that, just run the `sh.py` file:

```bash
python sh.py
```
